## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/FuseMachine-2026-Fellowship.git
cd FuseMachine-2026-Fellowship
```

### 2. Set up a virtual environment

```bash
python -m venv venv
source venv/bin/activate      # Linux / macOS
venv\Scripts\activate         # Windows
```

### 3. Install dependencies

Each week folder may have its own `requirements.txt`:

```bash
cd Week_X_Name
pip install -r requirements.txt
```

### 4. Run a project

Follow the instructions inside each week's folder (a README or notebook, where available).
